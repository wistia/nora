**S3 IAM credentials** — omitting static S3 keys now uses AWS environment, IRSA,
EKS Pod Identity, ECS or EC2 credentials instead of silently sending unsigned
requests. Explicit NORA keys take precedence, and incomplete pairs are rejected.
Anonymous buckets and emulators must explicitly set `storage.s3_anonymous=true`
or `NORA_STORAGE_S3_ANONYMOUS=true`. See `docs/s3-credentials.md` for migration and
EKS setup details.
